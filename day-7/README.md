# Day 7 Installation Results

**Completed:** 2026-06-05  
**Focus:** OpenShift Lightspeed → MaaS gateway (Qwen3-4B-Instruct) — optional “drink your own champagne” demo

## Summary

Day 7 wires **OpenShift Lightspeed** to the same **MaaS gateway** built in Days 1–6. Lightspeed uses a dedicated MaaS API key and calls governed **Qwen3-4B-Instruct** inference at `${MAAS_URL}/v1` — the platform consuming its own model service.

| Criterion | Result |
|-----------|--------|
| Lightspeed Operator | **Pass** — pre-installed |
| Qwen vLLM tool calling | **Pass** — `--enable-auto-tool-choice` + `--tool-call-parser=hermes` (pre-configured) |
| Qwen on MaaS (MaaSModelRef + BBR) | **Pass** |
| OLSConfig → MaaS gateway | **Pass** |
| `lightspeed-app-server` Ready | **Pass** |
| MaaS inference probe (same key) | **Pass** — HTTP 200 |
| MaaS tool_choice auto probe | **Pass** — HTTP 200 (no 400) |

**Why Qwen, not Granite tiny:** Lightspeed requires `tool_choice: "auto"`. Qwen3-4B is already deployed with Hermes tool-calling flags and delivers much better cluster Q&A quality than 1B Granite tiny. Granite remains available for other MaaS demos (BBR, auth, rate limits).

Day 7 uses admin-minted Lightspeed key; persona keys from Day 6 remain separate. Multi-user setup: [MULTI-USER-ACCESS.md](../MULTI-USER-ACCESS.md).

## Architecture

```
OpenShift Console (Lightspeed UI)
  → lightspeed-app-server
  → MaaS Gateway (${MAAS_URL}/v1)
  → Authorino + quotas (demo-openshift-lightspeed subscription)
  → Qwen3-4B-Instruct (qwen3-4b-instruct)
```

## Install

```bash
cd PoC/day-7
chmod +x run-day7-install.sh
./run-day7-install.sh
```

Creates:

- `MaaSModelRef` + BBR HTTPRoute for `qwen3-4b-instruct`
- `demo-openshift-lightspeed` subscription (Qwen, 50k TPM/min)
- `maas-gateway-api-key` secret in `openshift-lightspeed`
- `OLSConfig/cluster` with provider `maas-gateway`, default model `qwen3-4b-instruct`
- `lightspeed-maas.env` (local API key — gitignored)

## Optional demo: “Drink your own champagne”

**When to show:** After core demos (1–3) or as a closing “we use our own gateway” moment.  
**Duration:** 3–5 minutes  
**Required role:** cluster-admin (default for sandbox presenter)

### Steps

1. Open **OpenShift Console** (Administrator perspective)
2. Click the **OpenShift Lightspeed** icon (sparkle / assistant in header)
3. Ask a cluster question, for example:
   - *“How do I check GPU node capacity on this cluster?”*
   - *“What namespace are my LLM inference services in?”*
4. **Talking point:** Answers are generated by **Qwen3-4B** routed through the **MaaS gateway** — same auth, quotas, and observability stack as application workloads.

### Verify backend (optional, before presenting)

```bash
source day-7/lightspeed-maas.env

# Plain chat
curl -s -X POST "${MAAS_URL}/v1/chat/completions" \
  -H "Authorization: Bearer ${LIGHTSPEED_MAAS_KEY}" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3-4b-instruct","messages":[{"role":"user","content":"Hello from Lightspeed path"}],"max_tokens":20}'

# Tool calling (Lightspeed sends tool_choice: auto)
curl -s -o /dev/null -w "HTTP %{http_code}\n" -X POST "${MAAS_URL}/v1/chat/completions" \
  -H "Authorization: Bearer ${LIGHTSPEED_MAAS_KEY}" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3-4b-instruct","messages":[{"role":"user","content":"ping"}],"max_tokens":10,"tool_choice":"auto","tools":[{"type":"function","function":{"name":"noop","description":"No-op","parameters":{"type":"object","properties":{}}}}]}'
```

Expected: both return **HTTP 200**.

## Troubleshooting

| Symptom | Check |
|---------|-------|
| Lightspeed button greyed out | Log in as cluster-admin; see OLS RBAC docs |
| `lightspeed-app-server` not Ready | `oc logs -n openshift-lightspeed deploy/lightspeed-app-server -c lightspeed-service-api` |
| LLM errors in Lightspeed | Re-run MaaS probe with `lightspeed-maas.env` key |
| `tool_choice auto` HTTP 400 | Qwen pod missing vLLM flags — verify `--enable-auto-tool-choice` + `--tool-call-parser=hermes` on `qwen3-4b-instruct` |
| Unified BBR 404/502 for Qwen | Apply [manifests/bbr-qwen-httproute.yaml](manifests/bbr-qwen-httproute.yaml) |
| Key expired | Re-run `./run-day7-install.sh` (mints new 336h key) |

See [day-7/CHANGES.md](CHANGES.md) and [06-troubleshooting.md](../06-troubleshooting.md).
